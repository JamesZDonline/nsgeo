This is the first release of nsgeo, a QGIS plugin for processing GPR surveys in
their map context. It is **experimental**: QGIS lists it that way, and you should
expect rough edges and keep backups of your site folders.

**Start with the
[getting-started guide](https://github.com/JamesZDonline/nsgeo/blob/v0.1.0/docs/guide/getting-started.md).**
It covers installing, a first session from DZT files to slices, where your data
lives, and the known issues below.

## Install

Download `nsgeo_qgis-0.1.0.zip` from **Assets** below, not the *Source code*
downloads, which will not install. Do not unzip it. In QGIS, choose **Plugins →
Manage and Install Plugins… → Install from ZIP**, choose the zip, and click
**Install Plugin**. Click **Yes** at QGIS's security warning, which it shows for
any plugin installed from a zip. Then restart QGIS. Nothing else needs
installing.

## Runs on

- QGIS 3.40 to 3.44, and QGIS 4.x. Its zip is checked by installing it into
  QGIS 3.40, 3.44 and 4.2.
- Windows and Linux. macOS is untested.

## What's in it

- **Sites and grids.** Import GSSI DZT files into grids placed from GNSS corners,
  digitised on the map, or read from an existing polygon.
- **The map link.** Hover a line on the map to see its profile. The profile's
  cursor and selected range are drawn back onto the map.
- **Processing.** Time-zero, dewow, background removal (mean, sliding window or
  SVD), bandpass, three gains including a draggable gain curve, and amplitude
  transforms. Nothing runs unless you add it. A Difference view shows what each
  step removed, and presets and Apply to grid reuse a set of steps.
- **Picking.** Pick reflections on the profile into a QGIS point layer. Each pick
  records its two-way time, distance, depth and velocity.
- **Time and depth slices.** Slice a grid with an adjustable window, cell size and
  fill, and see each slice on the map. Save the volume, or export the slices as a
  multi-band GeoTIFF.

## Known limits

- **macOS is untested.**
- **[#22](https://github.com/JamesZDonline/nsgeo/issues/22):** unsaved edits in
  the picks layer can be lost when the grids' CRS changes. Save or discard
  picks-layer edits before you use any grid command: Add grid…, Edit grid…,
  Set velocity… or Remove grid.
- **[#23](https://github.com/JamesZDonline/nsgeo/issues/23):** moving or renaming
  the site's GeoPackage on its own can lose data. Move, copy or back up the whole
  site folder, with QGIS closed.
- **[#40](https://github.com/JamesZDonline/nsgeo/issues/40):** a dewow window of
  one sample, or a sliding background window of one trace, blanks the profile
  without a warning. An AGC window of one sample loses all the amplitude
  information, also without a warning. Keep these windows at least two samples
  (or two traces) wide.

The guide's *Known issues* section explains each one and its workaround in full.
