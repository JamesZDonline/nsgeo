nsgeo 0.2.0 adds a whole-site view to the slices, measured velocities, and
profiles that read the same way on every line of a zigzag survey. It also brings
a time cutoff, a rebuilt grid dialog, and many fixes from using 0.1.0 in the
field. It is still **experimental**: keep backups of your site folders.

**Start with the
[getting-started guide](https://github.com/JamesZDonline/nsgeo/blob/v0.2.0/docs/guide/getting-started.md).**

## Install or upgrade

Download `nsgeo_qgis-0.2.0.zip` from **Assets** below, not the *Source code*
downloads, which will not install. Do not unzip it. In QGIS, choose **Plugins →
Manage and Install Plugins… → Install from ZIP**, choose the zip, and click
**Install Plugin**. Click **Yes** at QGIS's security warning. Then restart QGIS.

If you have 0.1.0, install the new zip the same way; QGIS replaces the old
version. Restart QGIS afterwards, and check that **Plugins → nsgeo → About
nsgeo** reports `plugin 0.2.0 · core 0.2.0`. 0.2.0 opens surveys made with
0.1.0, and upgrading does not touch your site folders.

## Runs on

- QGIS 3.40 to 3.44, and QGIS 4.x. Its zip is checked by installing it into
  QGIS 3.40, 3.44 and 4.2.
- Windows and Linux. macOS is untested.

## What's new

### Slices

- **Whole site.** A *This grid / Whole site* switch at the top of the Slices
  panel shows every grid's slice together on one map layer, with one depth
  slider and one colour scale. Grids that differ in strength can be normalised.
  The whole site exports as one GeoTIFF.
- **Your settings are remembered.** Each grid remembers the cell size, dz, z0,
  z1 and fill radius you set for it, and the whole site remembers its own. They
  are saved with the survey. Opening a saved cube makes its settings that grid's
  remembered ones. ([#71](https://github.com/JamesZDonline/nsgeo/issues/71))
- **Fill radius in line spacings.** This grid's fill radius is set as a
  multiple of the line spacing, as Whole site's already was, with the metres
  shown beside the box. ([#72](https://github.com/JamesZDonline/nsgeo/issues/72))
- **New starting values.** Slices start on the Square transform, a 0.2 m cell
  (no larger than half the line spacing) and a fill radius of half a line
  spacing. ([#81](https://github.com/JamesZDonline/nsgeo/issues/81))
- **Moving between the two views.** Going back from Whole site to This grid
  opens the grid you selected in the site list, at the same time.
  ([#70](https://github.com/JamesZDonline/nsgeo/issues/70)) If every line you
  chose for a grid is later removed, both views use all the grid's remaining
  lines, and the line chooser won't accept an empty choice.
  ([#74](https://github.com/JamesZDonline/nsgeo/issues/74))

### Velocity

- **Measure a velocity from a diffraction hyperbola.** Click along a hyperbola
  on a profile, and nsgeo fits it and gives a velocity with its uncertainty.
  Fits are saved with the survey. **Set velocity…** now opens a dialog that
  chooses which fit sets a line's velocity, and so its depths.
  ([#55](https://github.com/JamesZDonline/nsgeo/issues/55))
- **Delete a saved fit** from that dialog. The selected fit is drawn on the
  profile while the dialog is open.
  ([#85](https://github.com/JamesZDonline/nsgeo/issues/85))

### Profiles and processing

- **Zigzag surveys.** Lines walked the other way are drawn mirrored, so every
  line on a grid reads against one ruler of metres along that grid. Zoom and the
  time window carry over between parallel lines.
  ([#67](https://github.com/JamesZDonline/nsgeo/issues/67))
- **Time cutoff.** A new processing step hides everything after a two-way time
  you set by dragging a line on the profile. It never changes your DZT files.
  ([#59](https://github.com/JamesZDonline/nsgeo/issues/59))
- **A steadier gain curve.** The profile's brightness scale holds still while
  you shape the gain curve, and a strip beside it shows the headroom left.
  ([#6](https://github.com/JamesZDonline/nsgeo/issues/6))
- **Clearer step names.** Steps have plain titles, and **Add step** groups them
  as Time, Filters, Background and Gain.
  ([#82](https://github.com/JamesZDonline/nsgeo/issues/82))

### Sites and grids

- **A rebuilt grid dialog.** Pick each corner from the map, from a GPS point or
  from a polygon, in any CRS, and **Fit** checks the corners against each other
  and shows how far off each one is.
  ([#63](https://github.com/JamesZDonline/nsgeo/issues/63))
- **Remove several lines at once,** or a grid together with its lines.
  ([#31](https://github.com/JamesZDonline/nsgeo/issues/31))
- **A Panels button** on the toolbar shows or hides each nsgeo panel, with
  layouts for profile work and slice work.
  ([#84](https://github.com/JamesZDonline/nsgeo/issues/84))
- **From the field:** the site's layers go on top of the Layers panel; Import
  DZT opens on the grid you selected; survey lines are drawn lighter; and Import
  DZT's *First line at* now starts at half the line spacing.
  ([#68](https://github.com/JamesZDonline/nsgeo/issues/68),
  [#61](https://github.com/JamesZDonline/nsgeo/issues/61),
  [#66](https://github.com/JamesZDonline/nsgeo/issues/66),
  [#69](https://github.com/JamesZDonline/nsgeo/issues/69))

## Known limits

- **macOS is untested.**
- **[#22](https://github.com/JamesZDonline/nsgeo/issues/22):** unsaved edits in
  the picks layer can be lost when the grids' CRS changes. Save or discard
  picks-layer edits before you use any grid command: Add grid…, Edit grid…,
  Set velocity… or Remove grid.
- **[#23](https://github.com/JamesZDonline/nsgeo/issues/23):** moving or renaming
  the site's GeoPackage on its own can lose data. Move, copy or back up the whole
  site folder, with QGIS closed.
- **[#40](https://github.com/JamesZDonline/nsgeo/issues/40):** a dewow window of
  one sample, or a sliding background window of one trace, blanks the profile
  without a warning. Keep these windows at least two samples (or two traces)
  wide.

The guide's *Known issues* section explains each one and its workaround in full.
Also open: dragging the depth slider in Whole site can lag on a large site
([#73](https://github.com/JamesZDonline/nsgeo/issues/73)), and reopening a saved
QGIS project can bring back a second, stale copy of the site's layers
([#78](https://github.com/JamesZDonline/nsgeo/issues/78)).
